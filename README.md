# 一線值班表產生器

麻醉科一線值班的選班表產生工具。單一 HTML 檔，用瀏覽器打開就能用，不需安裝任何東西。

## 怎麼用

線上版：<https://wilson-vghtpe-anes.github.io/duty-roster-generator/>
（或下載 `值班表產生器.html`，雙擊用瀏覽器開啟）

1. **住院醫師名單**：輸入姓名（可一次貼上多位），勾選本月要參與分配的人。
   產生器只用人數產生代號 A、B、C…，**不會把代號綁到任何人身上**。
2. **當月放假日**：點月曆格子切換放假／上班，班別會自動分類。
3. **班數配額**：自動算出每個代號各班別要值幾班，可手動微調。
4. **選班順序與匯出**：產生打勾矩陣，下載 .xlsx。
   誰是哪個代號在會議上抽籤，抽完在試算表的姓名欄下拉選人即可。

匯出的 .xlsx 用 Google 試算表的「檔案 → 匯入 → 上傳」匯進去，
下拉選單、公式、底色都會保留，共用連結設成「可以編輯」就能一起線上選班。

## 班別分類與權重

| 分類 | 判定方式 | 一線 | 8F 夜班 |
|---|---|---|---|
| W1-4 | 平日 | 1 | 0.3 |
| W5 | 隔天放假的上班日 | 1.5 | 0.5 |
| W6 | 連假中非最後一天 | 2.5 | 無 |
| W7 | 連假最後一天／單獨放假一天 | 2.5 | 無 |

平日有一線＋8 樓夜班，假日只有一線。

## 配額與選班順序怎麼決定

- **配額**：依下列優先順序分配（其他班別每人限平均 ±1 班內）：
  1. **W567 一線**（W5＋W6＋W7）班數每人最多差 1 班。總班數不另外要求接近。
  2. **週五班**（W5 一線、W5 8F）各自每人最多差 1 班，兩者合計也最多差 1 班
     （W5 多一班的人，W5 8F 就不會再多）。
  3. 每個代號的**加權總和**和平均的最大差距盡量小；差距相同時，再讓整體更貼近平均。
- **選班順序**：班別依序為 W5/W6/W7 一線 → W5 8F → W1-4 一線 → W1-4 8F
  （和週五相關的先選完，再處理 W1-4）。每個班別分成數輪，第 r 輪由「該班別配額 ≥ r」的代號參加
  （配額用完的代號該輪蓋灰）。每輪固定整條 A→末位 或 末位→A；方向預設逐輪交替，
  但不強制——某幾輪維持同方向如果能讓各代號更接近（差距改善超過 0.2%），就會不反轉。
  Round 1 一定由 A 開始選。W567、W1-4 的第一輪各自由 A 和末位代號中「該班別班數較多」的那個先選（一樣多就不限）；
  兩組第一輪也盡量反向，W567 第一個選的代號到 W1-4 第一輪會變成最後一個選。
- **公平性檢查**：每次選班的價值 ＝ 班別搶手度 × 輪到我時還剩多少比例的班可挑；
  每個代號取所有選班次的加權平均（W1-4 8F 不列入）。工具會試遍所有代號配對、並搭配調整各輪方向，
  挑出讓各代號分數差距最小的一組——因為代號是抽籤抽到的，只要各代號夠接近，抽到哪個都一樣公平。

## 環境需求

任何現代瀏覽器（Chrome / Edge / Safari / Firefox）。
下載 .xlsx 時會從 cdnjs 載入 ExcelJS，這一步需要連網；其餘功能完全離線可用。
名單與設定存在瀏覽器的 localStorage，只留在自己電腦上。
