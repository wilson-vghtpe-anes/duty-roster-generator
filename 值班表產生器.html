一線值班表產生器

勾選參與者 → 選假日 → 產生代號的配額與選班順序 → 匯出 Excel，代號對應誰再抽籤填入

1住院醫師名單

勾選本月要參與分配的人。產生器只用人數產生代號 A、B、C…，不會把代號綁到任何人身上； 誰是哪個代號請在會議上抽籤，抽完填進匯出的 Excel 裡的對應表即可。 「想值 / 不值」的欄位也在那份 Excel 上填。

名單 0 人，本月參與 0 人

2當月放假日

點格子切換「放假 / 上班」（預設週六日放假）。分類自動判定：連假最後一天＝W7、連假其餘天＝W6、 單獨一天＝W7、隔天放假的上班日＝W5、其餘＝W1-4。可用格內下拉手動鎖定（🔒）。

圖例： W1-4平日 W5隔天放假（權重 1.5） W6連假非最後一天（2.5） W7連假最後一天／單日假（2.5）

3各代號的班數配額

權重：W1-4 一線 1、W5 一線 1.5、W6/W7 一線 2.5、W5 8F 0.5、W1-4 8F 0.3。 平日有一線＋8樓夜班，假日只有一線。配額可手動修改，合計列會即時檢核。
想換代號：按住代號左邊的 ⠿ 上下拖曳，整列配額會移到新位置，選班方向也會跟著重算。
自動分配的優先順序：① 週五班（W5、W5 8F）每人最多差 1 班 → ② W567 一線權重（W5×1.5＋W6×2.5＋W7×2.5）每人盡量接近 → ③ 總權重盡量貼近平均。

4選班順序與匯出

每一輪固定整條 A→末位 或 末位→A（該輪沒份的代號跳過）。同一班別裡，參加人數少的輪次先選： 班數比別人多的人先在單人輪、部分人輪次選完，最後才是全部人都參加的輪次。 Round 1 一定由 A 開始選；其餘各輪的方向依可挑比例決定，讓各代號盡量接近。 自動配對代號時，W567 權重（W5×1.5＋W6×2.5＋W7×2.5）高的排在 A 這側、W1-4 班數多的排在末位那側； 兩者都一樣的人之間，W5 8F 越多（一樣多就看總權重越高）的越排在這群人的兩端。 每次選班的價值＝該班別搶手度 × 輪到我時還剩多少比例的班可挑 （＝你在意的任何一天，這時候還沒被選走的機率）；每個代號的分數是它所有選班次的加權平均， 灰格沒得選就不計分，所以分數與班數多寡無關。W1-4 8F 夜班值哪天差別不大，不列入分數。 因為代號是抽籤抽到的，只要讓各代號的分數盡量接近，抽到哪個都一樣公平。

打勾矩陣（匯出的 Excel 也是這張，格子是只有「OK」一個選項的下拉）：表頭的 A→F／F→A 是該輪的選班方向； 灰格 ＝該代號的那個班別配額已用完，該輪不用選。 按最上面的 ⇄ 可以把那一輪整輪反過來選，上面的可挑比例會跟著更新； 再按一次「讓各代號的可挑比例最接近」就回到自動決定的方向。

下拉選單只有 .xlsx 帶得動——資料驗證是試算表的物件，剪貼簿只能帶底色和文字。 如果一定要用貼上的，貼完再按「複製修補腳本」，到試算表 擴充功能 → Apps Script 貼上並執行一次，就會把下拉選單、公式和欄寬全部補回來。

  1. 按上面的下載 Excel (.xlsx)。
  2. 打開任何一份 Google 試算表 → 檔案 → 匯入 → 上傳，把剛下載的檔案拖進去。
  3. 「匯入位置」選 建立新試算表 → 匯入（下拉選單、公式、底色都會一起進來）。
    ※ 想沿用現有的連結和共用設定，就改選「取代目前工作表」，網址不會變。
  4. 抽籤決定誰是哪個代號，在最上面那張表的姓名欄下拉選單選人——選完選班順序表的姓名欄和月曆下拉都會跟著生效。
  5. 右上共用 → 取得連結 → 改成「知道連結的人可以編輯」，把連結發給大家。
